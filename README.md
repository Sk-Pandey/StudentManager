# StudentManager

StudentManager is a modern web-based student management application built with React, Vite, Tailwind CSS, and DaisyUI. It provides a simple and responsive interface for managing student records efficiently.

## Features

* Add new students
* Edit student information
* Delete student records
* Responsive UI for desktop and mobile devices
* Fast performance powered by Vite
* Modern design using Tailwind CSS and DaisyUI

## Tech Stack

* React
* Vite
* Tailwind CSS
* DaisyUI
* UUID
